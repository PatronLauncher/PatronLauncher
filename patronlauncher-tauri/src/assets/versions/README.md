# Sürüm kapakları

`<sürüm>.webp` dosyaları `src/versionArt.ts` tarafından bulunur: önce tam sürüm (26.2, 1.21.11),
yoksa aile (1.21, 26). Kapakların kaynağı `Docs/KapakFotograflari` klasörüdür; orada olmayan
sürümler (1.20, 1.9–1.11 ve 1.6 öncesi) önceki görselleri kullanır. Yeni dosya eklemek için aynı adla
buraya koyup uygulamayı yeniden derlemek yeterlidir; dosya yoksa aileye özel gradient görünür.
